## 💡 A-LA-CARTE SALES RECOMMENDATIONS

### Strategy Overview

Enable customers to purchase individual features or feature bundles on top of their base tier subscription. This allows:

1. **Flexibility:** Customers only pay for what they need
2. **Upsell Opportunities:** Easy path to upgrade without full tier change
3. **Competitive Advantage:** More granular pricing than competitors
4. **Revenue Optimization:** Capture value from specific feature needs

### Implementation Approach

#### Option 1: Feature Add-Ons (Recommended)
- Add individual features as purchasable add-ons
- Features can be added to any tier (with prerequisites)
- Monthly or annual billing
- Can be cancelled anytime

#### Option 2: Feature Bundles
- Group related features into bundles
- Offer discounts for bundles vs. individual features
- Examples:
  - "AI Suite Bundle" (6 Full AI Features)
  - "Enterprise Bundle" (7 Enterprise Features)
  - "aCOS Bundle" (12 aCOS Features)
  - "Visionary Bundle" (14 Visionary Features)

#### Option 3: Hybrid Model
- Base tier subscription (required)
- Individual features (a-la-carte)
- Feature bundles (discounted)
- Full tier upgrade (best value)

## 💰 FEATURE PRICING RECOMMENDATIONS

### Pricing Philosophy

1. **Value-Based Pricing:** Price based on value delivered, not cost
2. **Tier Discounts:** Lower tiers pay more per feature (higher margins)
3. **Bundle Discounts:** 10-15% discount for bundles
4. **Annual Discounts:** 10-15% discount for annual vs. monthly

### Recommended Pricing Structure

#### Foundation Tier Customers
- **Individual Features:** Base price × 2 (premium for lower tier)
- **Example:** AI Contract Analyzer = $500 × 2 = $1000/year

#### Essentials Tier Customers
- **Individual Features:** Base price × 1.5
- **Example:** aCOS Goals = $800 × 1.5 = $1200/year

#### Growth Tier Customers
- **Individual Features:** Base price × 1.2
- **Example:** Physical AI = $5,000 × 1.2 = $6,000/year

#### Visionary Tier Customers
- **Individual Features:** Base price × 1.0 (standard pricing)
- **Example:** All features included, but can add extras at standard pricing

### Step 3: Update Tier Service

Modify `tierService.ts` to check for feature subscriptions:

```typescript
async checkFeatureAccess(
  organizationId: string,
  feature: keyof TierFeatures
): Promise<FeatureCheckResult> {
  // Check tier access first
  const currentTier = await this.getOrganizationTier(organizationId);
  const tierHasFeature = hasFeature(currentTier, feature);
  
  if (tierHasFeature) {
    return { allowed: true, currentTier, feature, displayName: FEATURE_DISPLAY_NAMES[feature] };
  }
  
  // Check if feature is purchased as add-on
  const featureSubscription = await prisma.featureSubscription.findFirst({
    where: {
      organizationId,
      featureId: feature,
      status: 'active',
      OR: [
        { endsAt: null },
        { endsAt: { gt: new Date() } }
      ]
    }
  });
  
  if (featureSubscription) {
    return { allowed: true, currentTier, feature, displayName: FEATURE_DISPLAY_NAMES[feature] };
  }
  
  // Feature not available
  const requiredTier = TIER_ORDER.find(tier => hasFeature(tier, feature));
  return {
    allowed: false,
    requiredTier,
    currentTier,
    feature,
    displayName: FEATURE_DISPLAY_NAMES[feature],
    upgradeMessage: `Purchase ${FEATURE_DISPLAY_NAMES[feature]} as add-on or upgrade to ${requiredTier}`,
  };
}
```

// POST /api/billing/features/:featureId/subscribe
async subscribeToFeature(req, res) {
  const { featureId } = req.params;
  const { billingCycle } = req.body;
  const organizationId = req.user.organizationId;
  
  // Validate feature exists and is available as add-on
  const feature = FEATURES[featureId];
  if (!feature || !feature.availableAsAddOn) {
    return res.status(400).json({ error: 'Feature not available as add-on' });
  }
  
  // Check prerequisites
  if (feature.requiresTier) {
    const currentTier = await tierService.getOrganizationTier(organizationId);
    if (!isTierAtLeast(currentTier, feature.requiresTier)) {
      return res.status(403).json({ error: `Requires ${feature.requiresTier} tier` });
    }
  }
  
  // Create Stripe subscription item
  const priceId = billingCycle === 'annual' 
    ? feature.stripePriceIdAnnual 
    : feature.stripePriceIdMonthly;
  
  const subscriptionItem = await stripe.subscriptionItems.create({
    subscription: organization.subscriptionId,
    price: priceId,
  });
  
  // Create feature subscription record
  const featureSubscription = await prisma.featureSubscription.create({
    data: {
      organizationId,
      featureId,
      status: 'active',
      billingCycle,
      price: billingCycle === 'annual' ? feature.basePriceAnnual : feature.basePriceMonthly * 12,
      stripeSubscriptionItemId: subscriptionItem.id,
      stripePriceId: priceId,
      startsAt: new Date(),
    }
  });
  
  return res.json({ featureSubscription });
}
