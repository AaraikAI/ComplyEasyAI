## 🔧 TECHNICAL SEO CHECKLIST

### On-Page SEO

- [ ] **Title Tags** (50-60 characters)
  - Include primary keyword
  - Include brand name
  - Compelling & click-worthy

- [ ] **Meta Descriptions** (150-160 characters)
  - Include primary keyword
  - Include call-to-action
  - Compelling value prop

- [ ] **H1 Tags**
  - One H1 per page
  - Include primary keyword
  - Clear & descriptive

- [ ] **Header Hierarchy** (H1 → H2 → H3)
  - Logical structure
  - Include keywords in H2s
  - Scannable

- [ ] **Image Optimization**
  - Alt text with keywords
  - Compressed (WebP format)
  - Descriptive file names
  - Lazy loading

- [ ] **Internal Linking**
  - 5-10 internal links per page
  - Descriptive anchor text
  - Link to pillar pages
  - Link to related content

- [ ] **External Links**
  - Link to authoritative sources
  - Open in new tab
  - Rel=nofollow for paid links

- [ ] **Schema Markup**
  - Organization schema
  - Article schema
  - FAQ schema
  - Review schema
  - Breadcrumb schema

- [ ] **URL Structure**
  - Short & descriptive
  - Include keywords
  - Hyphens (not underscores)
  - Lowercase

### Technical SEO

- [ ] **Site Speed**
  - Core Web Vitals passing
  - LCP < 2.5s
  - FID < 100ms
  - CLS < 0.1
  - PageSpeed Insights score 90+

- [ ] **Mobile Optimization**
  - Responsive design
  - Mobile-friendly test passing
  - Touch targets 48x48px+
  - No horizontal scrolling

- [ ] **HTTPS**
  - SSL certificate
  - All pages HTTPS
  - HTTP → HTTPS redirect

- [ ] **XML Sitemap**
  - /sitemap.xml
  - Submit to Google Search Console
  - Submit to Bing Webmaster Tools
  - Update weekly

- [ ] **Robots.txt**
  - /robots.txt
  - Allow all important pages
  - Disallow admin, API
  - Link to sitemap

- [ ] **Canonical Tags**
  - Self-referencing canonical on all pages
  - Prevent duplicate content

- [ ] **404 Page**
  - Custom 404
  - Helpful navigation
  - Search box

- [ ] **Structured Data**
  - JSON-LD format
  - Test with Rich Results Test
  - No errors

### Content SEO

- [ ] **Keyword Density**
  - Primary keyword: 1-2%
  - Natural placement
  - Avoid keyword stuffing

- [ ] **Content Length**
  - Pillar pages: 3,000-5,000+ words
  - Blog posts: 1,500-2,500+ words
  - Landing pages: 1,000-2,000+ words

- [ ] **Readability**
  - Flesch Reading Ease: 60-70
  - Short paragraphs (2-3 sentences)
  - Bullet points & lists
  - Subheadings every 300 words

- [ ] **Content Freshness**
  - Update quarterly
  - Add publish/update dates
  - Keep content current

- [ ] **E-E-A-T Signals**
  - Author bios
  - Citations & sources
  - Expert reviews
  - Trust signals

### Off-Page SEO

- [ ] **Backlink Strategy**
  - Guest posting
  - PR / media mentions
  - Partner links
  - Directory submissions

- [ ] **Social Signals**
  - Share buttons on content
  - Twitter, LinkedIn, Facebook
  - Encourage sharing

- [ ] **Local SEO** (if applicable)
  - Google My Business
  - NAP consistency
  - Local citations
