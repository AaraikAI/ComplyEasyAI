### What's the difference between SOC 2 Type I and Type II?
**SOC 2 Type I**:
- **Scope**: Point-in-time assessment
- **Duration**: Single day/moment
- **Purpose**: "Controls are designed appropriately"
- **Timeline**: 4-8 weeks
- **Cost**: Lower ($15K-$25K typical audit fee)

**SOC 2 Type II**:
- **Scope**: Operating effectiveness over time
- **Duration**: 3-12 months observation period
- **Purpose**: "Controls operate effectively over time"
- **Timeline**: 6-12 months
- **Cost**: Higher ($25K-$75K typical audit fee)

**Most customers want**: Type II (required by enterprise buyers).

**ComplyEasyAI supports**: Both Type I and Type II with continuous control monitoring.
